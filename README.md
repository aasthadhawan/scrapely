A full-stack digital scrapbook web application that allows users to create, organize, and preserve their memories digitally. Users can create scrapbook pages, upload images, add descriptions, and manage their scrapbook collections through an intuitive and responsive interface.

## 🌐 Live Demo
🔗 https://scrapely-soee.onrender.com

## 📂 GitHub Repository

🔗 https://github.com/aasthadhawan/scrapely

---

## ✨ Features

- 🔐 User Authentication (Sign Up, Login & Logout)
- 📖 Create, edit and delete scrapbooks
- 📄 Add multiple scrapbook pages
- 🖼 Upload images using Cloudinary
- 📝 Add descriptions to scrapbook pages
- ☁️ Cloud image storage
- 📱 Responsive design for desktop and mobile
- 🎨 Clean and user-friendly interface

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/aasthadhawan/scrapely.git
```

Navigate to the project

```bash
cd scrapely
```

Install dependencies

```bash
npm install
```

Create a `.env` file with the required environment variables.

Start the application

```bash
npm start
```

The application will run locally at

```
http://localhost:3000
```

---

## 🔑 Environment Variables

Create a `.env` file in the project root and add:

```env
MONGODB_URI=your_mongodb_connection_string
CLOUDINARY_URL=your_cloudinary_url
```
